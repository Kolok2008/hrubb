# 🍄 Mushroom Hollow

**Атмосферный 3D-симулятор тихой охоты от первого лица в осеннем лесу**, созданный на базе **Three.js, React, TypeScript, GSAP и Web Audio API**.

Отправляйтесь на рассвете в процедурно сгенерированный осенний лес, выслеживайте 9 видов грибов (включая редких «живых» беглецов на корнях), подкрадывайтесь по мягкому мху, сушите урожай у костра, отбивайтесь от волков, улучшайте снаряжение в собственной уютной избушке и открывайте все тайны чащи.

## ✨ Ключевые особенности релизной версии

- **Кинематографичное меню у костра и живая усадьба** — стартовая камера плавно парит у потрескивающего костра, деревянной избушки с проработанным интерьером (резная кровать с пледом, верстак с атласом и масляной лампой, полки с банками, ковёр, карта леса на стене), лавки скупщика и уличной сушилки.
- **Тихая охота и «живые» грибы** — акустический стелс по 5 типам поверхностей (`мох`, `тропа`, `дерево`, `сухие листья`, `камень`), точный срез ножом по зелёной линии, а также пугливые редкие грибы, которые при шуме выпрыгивают на корнях, убегают в чащу и зарываются в листву, оставляя след спор.
- **Динамическая погода и события дня** — смена **Ясной осени**, **Лесного тумана** и **Грибного дождя** (снижает шум шагов на 30% и ускоряет рост грибов), объёмные солнечные лучи, 5 редких лесных событий и мистические **Ведьмины круги**.
- **Выживание, тактика и физика** — подбор и бросок камней/веток (`G` → `Q`) для отвлечения волков и спугивания грибов из куч листьев, разрушаемые деревянные ящики с бонусными грибами, катящиеся брёвна, комбо-удары и заряженный выпад ножом.
- **Прокачка и экономика лагеря** — уличная сушилка грибов (`×1.6` / `×1.75` к цене), 4 ножа с уникальными характеристиками, 7 улучшений в мастерской (корзина, сапоги лесника, сушилка, травяной термос на `H`, определитель, компас, мощный налобный фонарь на `L`), заказы дня и итоговый рейтинг вылазки (`S / A / B / C`).
- **100% процедурный звук и графика** — ни одного внешнего аудиофайла: шаги по 5 поверхностям, треск костра, дождь, ветер, совы, волки, щелчок фонарика и генеративная лесная музыка синтезируются в реальном времени через Web Audio API.
- **Двуязычный интерфейс и адаптивность** — мгновенное переключение **Русский / Українська** в меню и настройках, полная поддержка сенсорного управления на мобильных устройствах и автоматическая защита от медленного программного WebGL.

## 🔄 Главные отличия от базовой версии на GitHub

Если вы знакомы с ранним прототипом проекта, в текущей релизной версии игра прошла полную переработку:

1. **Меню и усадьба** — статичный экран заменён кинематографичной 3D-сценой у костра; добавлены зоны отчуждения лагеря (костёр и постройки больше не пересекаются с камнями и деревьями), обставленная избушка с новой кроватью и рабочими интерактивными станциями.
2. **Новые игровые механики** — ручной фонарик (`L`) с апгрейдом до налобного, динамическая погода и 5 лесных событий, уличная сушилка, травяной термос (`H`), подбор и бросок камней/веток (`G`/`Q`), 10 достижений и отчёт с рангом дня (`S/A/B/C`).
3. **Естественная визуализация** — добавлены объёмные лучи света, система частиц костра, дождя и светлячков; убраны искусственные кольца шума на земле и ореолы под грибами — обратная связь строится через живой звук и анимацию.
4. **Физика, аудио и комфорт** — 6-DOF пружинная физика камеры, 3-фазный хореограф шагов на GSAP, разрушаемые ящики, 5 типов поверхностей, полная локализация `RU / UA` и сохранение прогресса `v2`.

## 🚀 Быстрый старт

### Требования
- **Node.js** `18+` (рекомендуется `20+`)
- **npm** `9+`
- Современный браузер с поддержкой **WebGL 2** и **Web Audio API**

### Установка и запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск сервера разработки (http://localhost:3000)
npm run dev
```

### Основные npm-скрипты

| Команда | Назначение |
| :--- | :--- |
| `npm run dev` | Запуск локального Vite-сервера на `http://0.0.0.0:3000` |
| `npm run build` | Production-сборка оптимизированного бандла в `dist/` |
| `npm run preview` | Локальный предпросмотр собранной production-версии |
| `npm run lint` | Проверка строгой типизации TypeScript (`tsc --noEmit`) |

## 🎮 Краткая шпаргалка управления

| Клавиша | Действие |
| :--- | :--- |
| `W A S D` | Передвижение по лесу |
| `Shift` / `C` | Бег (расходует выносливость) / Тихий присед (скрытность) |
| `ЛКМ` | Присесть и срезать гриб / поймать беглеца / быстрый удар ножом |
| `ПКМ` или `F` | Комбо ножом / зажать для заряженного мощного выпада |
| `E` | Взаимодействие в лагере (скупка, верстак, сушилка, костёр, кровать) и поимка гриба на бегу |
| `G` / `Q` | Подобрать камень или ветку (до 3 шт.) / Бросить для отвлечения волка или выгона гриба из листьев |
| `L` | Включить / выключить фонарик (доступен с 1-го дня, усиливается в мастерской) |
| `H` | Выпить горячий травяной чай из термоса (+здоровье и выносливость) |
| `R` | Вытереть грязное лезвие ножа платком |
| `1` – `4` | Быстрая смена купленного ножа |
| `M` / `Tab` / `Esc` | Карта леса / Дневник лесника (атлас + достижения) / Пауза |

> Полную таблицу управления (включая мобильные сенсорные кнопки), таблицы всех грибов, ножей, улучшений и тактические советы читайте в **[docs/GAMEPLAY.md](./docs/GAMEPLAY.md)**.
